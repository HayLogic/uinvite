# Նյութեր

- `velvet.svg` — նախագծի առանձին ընթացակարգային թավշյա տեքստուրան։
- `music.mp3` — օգտատիրոջ տրամադրած `Happy-New-Year(chosic.com).mp3` երաժշտությունը։

Ծրարը, ծառի պատկերով ոսկեգույն կնիքը և լույսերով տոնածառը ստեղծված են CSS/SVG առանձին շերտերով։ Լրացուցիչ պատկերներ պարտադիր չեն։ Հղում-նկարը կայքում չի օգտագործվում։

- `gold-seal.png` — առանձին ստեղծված ոսկեգույն կնիք՝ տոնածառի ռելիեֆով։
- `envelope-velvet.png` — առանձին ստեղծված մուգ բորդո թավշյա նյութ՝ ծրարի շերտերի համար։
- Հիմնական տոնածառը Canvas-ի տեղային անիմացիոն լույսեր են, ոչ նկար։

- `welcome-background.png` — հատուկ ստեղծված լայն բորդո և ոսկեգույն տոնական ֆոն՝ «Լավագույն պահերը՝ միասին» բաժնի համար։ Նկարը դեկորատիվ է․ ամբողջ տեքստը մնում է HTML-ում։
- `welcome-background-mobile.png` — նույն ձևավորման ուղղահայաց տարբերակը փոքր էկրանների համար։
- `christmas-gifts.png` — առանձին ստեղծված տոնական նվերներ՝ թափանցիկ ֆոնով, ավարտական նվերների բաժնի համար։
