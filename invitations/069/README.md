# Հրավիրատոմս 069

Առաջին էջ՝ հղում-նկարի ոճով. բաց կրեմագույն ձյունածածկ անտառ, ձիթապտղագույն ծրար, մուգ կանաչ ժապավեն, եղևնու ճյուղերով և տոնածառի պատկերով մոմե կնիք։

`CONFIG`-ում `Patricia & Adam` անունները օրինակային են՝ վերցված դիզայնի հղումից։ Իրական անուններ, միջոցառման ամսաթիվ, վայր ու հետագա բաժինների պահանջներ դեռ չեն տրվել։ Բացվելուց հետո ցուցադրվում է միայն նախնական ներսի քարտը․ ամբողջական միջոցառման էջ դեռ չի ստեղծվել։

## Գործարկում

Պահոցի արմատից՝ `python3 -m http.server 8000`։ Այս տարբերակի ուղին է `/invitations/069/`։ Կամ այս պանակից՝ `npx serve .`։ Կարելի է անմիջապես բացել `index.html`-ը։

cPanel-ում վերբեռնեք այս պանակի `index.html`, `style.css`, `script.js` և `assets/`-ը առանձին document root-ում։ Build և կախվածությունների տեղադրում պետք չեն։

Անտառն ու կնիքի դեկորը ստեղծված առանձին պատկերներ են։ Ծրարի փեղկերն առանձին CSS/SVG շերտեր են։ Բացման կոճակը հասանելի է ստեղնաշարով, կրկնակի սեղմումները կանխված են, նվազեցված շարժման ռեժիմը հարգվում է։

Pinyon Script տառատեսակը Google Fonts-ի պաշտոնական պահոցից է և ներառված է տեղային՝ իր SIL Open Font License-ով (`assets/PinyonScript-OFL.txt`)։
