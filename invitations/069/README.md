# Հրավիրատոմս 069

Նոր հրավիրատոմսի առանձին աշխատանքային պանակ։ Դիզայնի հղումը, միջոցառման տվյալներն ու նյութերը դեռ չեն տրամադրվել։

Իրականացման ֆայլերը՝ `index.html`, `style.css`, `script.js`, `assets/`։ Տեխնոլոգիաները՝ HTML, CSS և vanilla JavaScript՝ առանց build-ի, cPanel-ի համար հարաբերական հղումներով։

068 տարբերակը պահոցի արմատում է․ նոր աշխատանքի ընթացքում այն չփոխել։
