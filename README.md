# Uinvite · Ամանորյա հրավիրատոմս

Responsive HTML, CSS և vanilla JavaScript հրավիրատոմս՝ առանց build-ի կամ կախվածությունների։

## Գործարկում

Նախագծի պանակում՝ `python3 -m http.server 8000`։ Հնարավոր է նաև անմիջապես բացել index.html-ը։ cPanel-ում վերբեռնեք `index.html`, `style.css`, `script.js` և `assets/` պանակը document root-ում։ Բոլոր ֆայլային հղումները հարաբերական են։

## Լրացնել հրապարակումից առաջ

`script.js`-ի սկզբի `CONFIG`-ում փոխարինեք օրինակային ընկերությունը, ամսաթիվը/ժամը (`YYYY-MM-DDTHH:mm:ss+04:00`), վայրը, հասցեն և քարտեզի իրական URL-ը։ Դատարկ քարտեզի դեպքում կոճակը թաքնված է։ `demoMode: false`-ը հեռացնում է օրինակային տվյալների նշումը։

Ավելացրեք `assets/music.mp3`։ Առանց ֆայլի երաժշտության կոճակը ցույց է տալիս դրա անհասանելիությունը, իսկ էջը շարունակում է աշխատել։

RSVP-ի համար լրացրեք `rsvpEndpoint` և անջատեք `demoMode`-ը։ Առանց endpoint-ի ձևը միշտ ցուցադրական է և չի ուղարկում/պահպանում տվյալները։ `sendRSVP()`-ը ուղարկում է JSON՝ `fullName`, `attendance` (`yes`/`no`), `guests` (մասնակցելու դեպքում՝ 1, մերժման դեպքում՝ 0․ ձևում հյուրերի քանակի դաշտ չկա), `comment`։ API-ն պետք է վերադարձնի 2xx միայն ընդունված պատասխանի դեպքում։ Սերվերում անհրաժեշտ են վավերացում, չարաշահումների սահմանափակում և համապատասխան CORS։ Գաղտնի բանալիներ frontend-ում չեն օգտագործվում։

Հետհաշվարկը հաշվարկվում է +04:00 ժամային գոտով։ Բացման կոճակը ստեղնաշարով հասանելի է, նվազեցված շարժման նախապատվությունը հարգվում է։ Ծրարն ու դեկորները առանձին CSS/SVG շերտեր են։
