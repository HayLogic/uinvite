# Uinvite — Christmas invitation

Ամանորյա կորպորատիվ վեբ հրավիրատոմսի նախագիծ։

## Տեխնոլոգիաներ
HTML, CSS, vanilla JavaScript։ Build կամ npm install չի պահանջվում։

## Տեղային դիտում
Նախագծի պանակում գործարկեք `python3 -m http.server 8000` և բացեք http://localhost:8000 ։ Կարելի է նաև բացել index.html-ը անմիջապես։

## Կառուցվածք
- index.html — էջի կառուցվածք
- style.css — ձևավորում
- script.js — CONFIG և ինտերակտիվություն
- assets/ — պատկերներ և music.mp3
- AGENTS.md — Codex-ի աշխատանքային հրահանգներ

## cPanel
Վերբեռնեք index.html, style.css, script.js և assets պանակը համապատասխան document root պանակում։

Այս commit-ը մեկնարկային միջավայր է։ Վերջնական դիզայնը, երաժշտությունը և իրական RSVP ինտեգրացիան դեռ չեն իրականացվել։
