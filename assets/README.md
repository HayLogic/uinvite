# Assets

Ավելացրեք առանձին պատկերները և music.mp3 երաժշտությունը այստեղ։

Առաջարկվող պատկերներ՝ բորդո թավշյա տեքստուրա, թափանցիկ ֆոնով ոսկեգույն կնիք և տոնական դեկորներ։ Օգտագործեք միայն ձեզ պատկանող կամ համապատասխան թույլտվությամբ նյութեր։

Այս պանակում դեռ իրական պատկերներ կամ երաժշտություն չկան։
